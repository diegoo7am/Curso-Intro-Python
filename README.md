# Introducción a Python para las Finanzas

Curso de introducción a Python orientado a las finanzas. Todos los ejemplos y ejercicios, también los de fundamentos, utilizan casos financieros: carteras, cotizaciones, impuestos, dividendos, rentabilidades, valoración de inversiones, etc.

## Índice del curso

Abre el notebook índice en Google Colab: [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/diegoo7am/Curso-Intro-Python/blob/main/indice.ipynb)

## Cómo trabajar

- Todo el curso se hace en **Google Colab**: no hace falta instalar nada, solo necesitas una cuenta de Google.
- Abre cada notebook con su botón *Open in Colab*.
- Antes de empezar a escribir, guarda tu propia copia con *Archivo → Guardar una copia en Drive* y trabaja siempre sobre ella; si no, perderás tus cambios al cerrar la pestaña.
- En cada clase se explica el notebook y después hay tiempo para hacer los ejercicios, que puedes terminar en casa.
- Las soluciones aparecen marcadas con 🔒 hasta que se publiquen.
- Algunos notebooks descargan datos de Yahoo Finance, así que necesitan conexión a internet. Los resultados pueden cambiar según la fecha en que se ejecuten.
